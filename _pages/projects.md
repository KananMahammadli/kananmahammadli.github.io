# Projects

* **Early Sepsis Detection** (Feb. 2024 – June 2024)  
- Sequence Models course project supervised by [Prof. Erdem Akagunduz](https://avesis.metu.edu.tr/akaerdem).
- 7-step-ahead forecasting for sepsis detection using sequential EHR data.
- Custom loss design to penalize late predictions and handle class imbalance.

* **Breast Cancer Classification via Data Augmentation** (Mar. 2022 – July 2022)
- Machine Learning course project supervised by [Prof. Seyda Ertekin](https://avesis.metu.edu.tr/sertekin).
- Used Vision Transformer + class-specific augmentations to boost F1-score of minority classes.
